# Task Manager

A simple task manager web app built with HTML, CSS and JavaScript.

**Live demo:** https://preethivishali15.github.io/task-manager-app

## Features
- Add tasks with priority and due date
- Mark tasks done, edit and delete
- Filter by status and priority
- Overdue tasks highlighted
- Data saved in the browser (localStorage)
- Responsive layout with light and dark mode

## Tech
HTML5, CSS3, JavaScript (ES6), localStorage
